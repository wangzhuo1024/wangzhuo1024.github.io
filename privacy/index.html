隐私政策 (Privacy Policy)

本站非常重视你的隐私。但在我们开始长篇大论之前，必须先澄清一个硬核的技术事实：本站是一个基于 Hexo 构建、部署在 GitHub Pages 上的纯静态博客。
这意味着，作为站长的我，并没有自己的后端服务器和数据库。你的数据并没有存在我的个人硬盘里，而是飘荡在各大互联网巨头和云服务的机房中。

通过本《隐私政策》，我将向你透明地展示：当你访问 wangzhuo1024.github.io 时，你究竟在跟谁交换信息。

协议最新更新时间：2026年8月20日。

一、 当你只是静静潜水时（访问数据收集）

当你打开本站的页面时，除了提供底层基础设施的第三方服务商，本站还主动引入了深度的行为分析工具。

1. 托管与 CDN 服务

  • GitHub Pages：本站托管于 GitHub。当你访问时，GitHub 的服务器会记录你的 IP 地址、浏览器 User-Agent (UA) 等基础网络层信息，用于提供静态网页分发服务。
  • 公共 CDN 节点：本站主题引用的部分静态资源（JS/CSS/图标）可能托管在 jsDelivr、Cloudflare 等公共 CDN 上。加载这些资源时，CDN 提供商会获取你的 IP 和请求信息。

2. 深度行为观察：Microsoft Clarity

为了优化页面布局并了解访客的阅读习惯，本站接入了 Microsoft Clarity。这不是简单的 PV/UV 统计，而是更深度的交互记录：

  • 会话录制 (Session Recordings)：Clarity 会匿名记录你在本站的浏览轨迹，包括你的鼠标移动路径、点击位置、页面滚动和窗口缩放行为。
  • 热力图 (Heatmaps)：系统会汇总所有访客的交互数据生成热力图，用于分析哪些内容最受关注，哪些区域的点击率异常。
  • 设备与网络特征：收集操作系统、浏览器型号、屏幕分辨率以及大致的地理位置（国家/地区级别）。
  • 隐私脱敏：请放心，Clarity 具备自动脱敏机制。你在评论框、搜索框中输入的文本内容会被自动屏蔽（以 * 号或空白代替），绝不会被录制到会话回放中。

3. 媒体与基础统计

  • 胶囊音乐：若你使用播放器，音频 API 提供商会记录播放请求。
  • 其他统计：如不蒜子等轻量级脚本，仅记录基础的访问量。

4. 我使用这些数据的目的

  • 观察访客在哪段代码或公式前“卡住了”（通过鼠标反复滚动或长时间停留）。
  • 排查移动端或特定浏览器下的 UI 错位问题。
  • 识别并过滤掉那些疯狂刷新页面的恶意爬虫。

二、 当你忍不住想吐槽时（评论与互动）

本站采用了无强制登录的评论系统（如 Twikoo / Waline 等）。这是一个高度自由的区域，你可以选择戴上面具，也可以留下真实的足迹。

1. 你主动留下的信息

  • 昵称：你随意。鼓励使用不易被恶意识别的代号，保护三次元隐私。
  • 邮箱：用于生成 Gravatar 头像以及在我回复时给你发送邮件通知。你的邮箱地址会被加密或哈希处理，绝对不会在前端公开显示。
  • 网址：选填。如果你有自己的小站，留下网址方便大家去你的地盘串门。

2. 系统被动记录的信息

为了防止你的评论和垃圾广告机器人混在一起，评论系统的后端服务会额外记录：

  • IP 地址：用于反垃圾判定。通常系统会将 IP 解析为你所在的省市（例如“来自河南”或“来自未知星系”），但绝对不会公开你的具体 IP 地址。
  • User-Agent (UA)：记录你使用的操作系统和浏览器版本。这主要是为了在评论区展示可爱的系统和浏览器小图标，同时也方便我在发现网页 Bug 时，快速定位是不是某个特定浏览器的兼容性问题。

实际上，没钱，没搞评论系统。XD

三、 你的数字脚印（Cookies 与 LocalStorage）

本站不查户口，但为了让你下次来的时候不用重新配置一切，你的浏览器里会留下一些微小的本地存储：

  • 系统配置记忆：你切换的深色/浅色模式、调整过的字体大小或音乐播放状态，会保存在浏览器的 LocalStorage 中。
  • 评论免登：评论系统会记住你上次填写的昵称和邮箱，方便你下次一键发送吐槽。
  • 访客身份标识：统计工具可能会写入一个无意义的随机 ID 到 Cookie 中，用来区分“同一个访客刷新了 10 次”和“10 个不同的访客”。

如何清除？ 你随时可以在浏览器的设置中清除本站的 Cookies 和 LocalStorage。清空之后，咱们就当是人生若只如初见。

四、 共享与转让

作为一个没有商业变现、全靠爱发电的个人博客：

  1. 绝不售卖：我没有任何理由、也没有任何渠道将你的隐私信息卖给广告商或数据贩子。
  2. 不主动共享：我不会与任何公司、组织或个人共享你的信息。
  3. 第三方免责：至于 GitHub、CDN 提供商或评论系统后端是如何处理他们服务器上产生的数据的，这超出了我的控制范围。详情请参考这些巨头们各自发布的隐私政策（比如微软隐私声明）。

五、 附属协议

虽然本站崇尚自由交流，但如果你触发了以下“防卫机制”：

  • 使用自动化脚本疯狂刷接口、发起 DDoS 攻击。
  • 在评论区发送包含恶意 XSS 代码或违规违法内容的评论。

为了保护其他访客的体验以及我可怜的 GitHub 仓库不被封禁，评论系统的防火墙或 GitHub 的安全机制可能会将你的 IP 地址关进“小黑屋”，短期内禁止你访问或评论。这种黑名单机制是自动且无情的，请谨慎测试边界。
